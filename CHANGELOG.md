# Historial de cambios

Los cambios destacados de cada versión se anotan aquí.

## [2.0.0] - 2026-10-26

### Mejoras

- Se reorganizaron las seis gráficas para que sus tipos y ejes correspondan a los datos que comparan.
- Se añadieron etiquetas de valores, nombres claros, unidades, colores distinguibles y formatos de moneda compactos.
- El análisis de empleados cambia entre comparación por año y evolución a lo largo del tiempo según el periodo elegido.
- Las capturas del README muestran el tablero y el detalle con datos reales de PostgreSQL en modo claro y oscuro.
- Se actualizó la versión del proyecto y se mantuvieron las exportaciones PDF y QR.
